# StopFungusGnats 🪴

A simple web tool for identifying and dealing with **fungus gnats** around plants.

## Features

* 🪰 Fungus gnat identification
* 🌱 Practical prevention and treatment information
* 📱 Responsive design
* ⚡ Fast and lightweight
* 🔍 SEO-friendly pages

## Tech Stack

* Astro
* JavaScript
* HTML / CSS

## Live Website

**StopFungusGnats** — https://stopfungusgnats.com/

## About

Built as a lightweight, focused web product designed to provide useful information to people dealing with fungus gnats in their plants.
